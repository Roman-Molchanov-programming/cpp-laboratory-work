# Система управления поездами

Консольное приложение на C++ для моделирования работы железнодорожного состава. Программа позволяет управлять поездами (указывать машиниста, задавать лимит вагонов) и прицеплять к ним вагоны различных типов с контролем вместимости.

## Особенности и функциональность

- **Объектно-ориентированная архитектура**:
  - `Carriage` — класс, описывающий номер и тип вагона (Плацкарт, Купе, Сидячий и др.).
  - `Train` — класс, хранящий информацию о машинисте, максимальном количестве вагонов и списке прицепленных вагонов (`std::vector<Carriage>`).
- **Ограничения состава**: проверка превышения лимита вагонов перед добавлением нового вагона в поезд.
