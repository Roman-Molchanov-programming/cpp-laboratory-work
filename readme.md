# Система управления поездами

Консольное приложение на C++ для моделирования работы железнодорожного состава. Программа позволяет управлять поездами (указывать машиниста, задавать лимит вагонов) и прицеплять к ним вагоны различных типов с динамическим полиморфизмом и контролем вместимости.

## Особенности и функциональность

* **Объектно-ориентированная иерархия и полиморфизм (Лабораторная работа №4):**
  * `Carriage` — абстрактный базовый класс с чисто виртуальными методами (`= 0`) и виртуальным деструктором.
  * `PassengerCarriage` — промежуточный класс для пассажирских вагонов, управляющий нижними и верхними местами.
  * `SeatingCarriage` — производный класс сидячего вагона (наследуется от `Carriage`).
  * `CompartmentCarriage` и `PlatskartCarriage` — производные классы купейного и плацкартного вагонов (наследуются от `PassengerCarriage`).
  * `Train` — класс, хранящий информацию о машинисте, максимальном количестве вагонов и полиморфном списке состава (`std::vector<std::shared_ptr<Carriage>>`).
* **Виртуальные и чисто виртуальные методы:**
  * `getComfortCategory()` — получение категории комфорта/обслуживания вагона.
  * `calculateTotalSeats()` — расчет общей вместимости мест.
  * `printVirtualInfo()` / `inputVirtualData()` — полиморфный ввод и вывод данных через перегруженные потоковые операторы `<<` и `>>`.
* **Современный C++20:**
  * Использование `std::string_view`, оператора трехстороннего сравнения `<==>` (`default`), умных указателей `std::shared_ptr` для безопасного управления жизненным циклом объектов.
* **Ограничения состава:** проверка превышения лимита вагонов перед добавлением нового вагона в поезд.
